07 // INSIGHTS

Notes From My Learning Journey

Ideas, concepts and lessons I explore while learning about cybersecurity, networking and development.

Application Security · 5 min read

Protecting Student Portals from SQL Injection

Student portals handle sensitive records, grades, and account details. Parameterized queries, strict input validation, least-privilege database accounts, and safe error handling help reduce the risk of SQL injection.

Key takeaway: never build SQL queries by concatenating untrusted input.
Development · 6 min read

Laravel vs. Node.js: Choosing the Right Backend

Both technologies can power business platforms. Laravel offers an integrated framework with conventions and built-in features, while Node.js is a flexible JavaScript runtime that fits event-driven services and JavaScript-based teams.

Key takeaway: choose based on project needs, team skills, and long-term maintenance.
System Design · 4 min read

Why Role-Based Access Control Matters

Not every user should see or change the same information. Role-based access control assigns permissions by responsibility, helping schools and businesses separate administrator, staff, and user capabilities.

Key takeaway: enforce permissions on the server, not only in the interface.
